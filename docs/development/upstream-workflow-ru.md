# Отдельный чат для бэклога pavelanni/examiner

По запросу U-005 от 2026-10-27. Основной проект:
https://github.com/pavelanni/examiner. Аккаунт разработчика: Fail-404.
[Руководство владельца fork](user-guide-ru.md) · [Журнал](work-log-ru.md)

## Как подготовить отдельное задание

При создании облачного задания выбрать репозиторий pavelanni/examiner,
ветку main. Если исходный проект недоступен в списке, дать существующему
подключению GitHub доступ к этому репозиторию через настройки подключения.
Выбор другого репозитория не выполняется простым переименованием папки.
Новый чат не получает автоматически историю этой беседы: передать ему
задание ниже, ссылку на нужную Issue и при необходимости ссылки на журнал.

В текущем сеансе чтение Issues исходного проекта успешно. GitHub API сообщает
для Fail-404 permissions.push=true в pavelanni/examiner. Это позволяет
рассматривать работу в отдельных ветках самого исходного проекта; отправка
Git в него пока не выполнялась. В новом сеансе проверить авторизацию и доступ
заново, а не считать их перенесёнными из текущего чата.

Если отправка ветки в исходный проект недоступна, можно работать в fork
Fail-404/examiner и открывать PR из него с назначением pavelanni/examiner.
Целевая Issue и назначение PR при этом остаются в исходном проекте.
Секреты и токены в сообщение задания не включать.

## Текст для нового чата

```text
Работай с исходным проектом https://github.com/pavelanni/examiner, ветка main.
Бэклог: https://github.com/pavelanni/examiner/issues.
Мой GitHub: Fail-404. Авторство Git: Fail-404,
115959997+Fail-404@users.noreply.github.com.

Прочитай AGENTS.md, CLAUDE.md и документацию проекта. Проверь фактическую
GitHub-авторизацию, права Git/API и существующие настройки автора коммитов.
Используй существующую рабочую копию; новое задание уже изолировано.

Изучи открытые Issues, связанные PR и зависимости. Если я указал номер Issue,
работай по нему. Иначе самостоятельно выбери одну небольшую задачу с понятными
критериями завершения и без незакрытых зависимостей. Проверь, не решается ли
она уже в другом PR. Кратко объясни выбор и приступай к работе.

Выполни полный цикл: отдельная ветка от актуальной main, реализация,
подходящие проверки, обновление пользовательской документации, коммит,
push ветки и PR в pavelanni/examiner:main со ссылкой на Issue.
Если Git-запись в исходный проект недоступна, отправь ветку в мой fork
Fail-404/examiner и создай PR из него в исходный проект. Не меняй происхождение
существующего origin вслепую: сначала выясни, какой репозиторий открыт.

Делай эту работу самостоятельно, без подтверждения каждой команды.
В main напрямую не отправляй изменения. Слияние PR и развёртывание
не входят в это задание. Закончить одним готовым PR по выбранной задаче;
постоянная фоновая работа не предполагается.

Новые комментарии в коде, заголовки, описания и комментарии в Issues/PR,
сообщения коммитов, инструкции и отчёты пиши по-русски. Идентификаторы,
названия API и команды сохраняй. Не переводи массово чужие старые комментарии.

Веди понятное описание того, что изменено, как проверить результат и как
пользоваться новой функцией. Сохраняй связь Issue → ветка → коммит → PR.
В отчёте различай выполненные проверки, непроверенные сценарии и ограничения.
Если задача требует недоступных прав или данных, заверши независимую работу
и укажи конкретный оставшийся блокер; пароль или токен в чат не запрашивай.
```

Для нескольких параллельных чатов назначать разные Issues и ветки. У каждого
чата должно быть отдельное облачное задание или отдельная локальная копия;
два агента в одной папке могут смешать незакоммиченные изменения.
История U/A в этой беседе сама по себе не является общей синхронизированной
нумерацией разных чатов. Для сквозной связи между чатами использовать Issue,
PR и SHA; при необходимости передать новому чату собственный префикс отчётов.

Исправление администратора уже отправлено в ветку
Fail-404/examiner:fix/admin-self-deactivation-u004.
[PR #2 в fork](https://github.com/Fail-404/examiner/pull/2) открыт в main fork.
Исходный коммит исправления:
[cc8e096](https://github.com/Fail-404/examiner/commit/cc8e096).
Коммит [cd227a6](https://github.com/Fail-404/examiner/commit/cd227a6)
переводит наши добавленные комментарии на русский язык.

Повторный push этого исправления не требуется. Для отправки автору исходного
проекта нужен отдельный PR с назначением pavelanni/examiner:main и источником
Fail-404:fix/admin-self-deactivation-u004. PR #2 внутри fork не становится
PR исходного проекта автоматически. Такой внешний PR в этом запросе не создавался.
Перед его созданием проверить актуальный исходный код и открытые PR на дубли.

Если новые коммиты позже появились только на Windows-ПК, их отправка из
этой ветки выполняется так:

```powershell
git status
git branch --show-current
git push -u origin fix/admin-self-deactivation-u004
```

Это относится к локальной копии, где origin указывает на Fail-404/examiner.
Push отправляет коммиты. Несохранённые в коммите изменения файлов он не отправит.
Настройка сервера приложения и изменение базы не являются push в GitHub.
